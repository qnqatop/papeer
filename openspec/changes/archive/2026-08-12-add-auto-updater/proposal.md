## Зачем

У Papeer нет встроенного механизма обновлений. Пользователи вынуждены вручную идти на GitHub Releases, искать нужный ассет под свою ОС, качать и заменять приложение. Это лишний трение: люди сидят на старых версиях, пропускают исправления и новые функции. Кнопка «Обновить» в настройках решает эту проблему.

## Что меняется

- **Новое**: `CheckForUpdates` — запрос к GitHub Releases API, сравнение последнего тега с текущей версией, ответ «доступно обновление» или «всё актуально»
- **Новое**: `DownloadUpdate` — скачивание нужного ассета (`.zip` для macOS/Windows, `.tar.gz` для Linux), распаковка во временную директорию, отчёт о прогрессе
- **Новое**: `InstallAndRestart` — замена запущенного бинарника/бандла на новый и перезапуск. Стратегии под каждую платформу: macOS заменяет `.app`-бандл, Windows через PowerShell-скрипт, Linux через `syscall.Exec`
- **Новое**: UI в Настройки → О программе — кнопка «Проверить обновления», сравнение версий, прогресс-бар загрузки, кнопка «Перезапустить для обновления», тумблер «Проверять обновления при запуске»
- **Новое**: Пассивная проверка при запуске — если доступна новая **major/minor** версия (patch игнорируется), показывается закрываемый баннер сверху с кнопкой «Обновить». Управляется тумблером; скрытая версия повторно не показывается
- **Новое**: Go-пакет `internal/updater/` — вся логика обновлений (HTTP, определение платформы, распаковка архивов, замена бинарника). Ассеты подбираются по шаблону `papeer-{macos|windows|linux}-*.{zip|tar.gz}` (имена совпадают с артефактами `release.yml`)

## Возможности (Capabilities)

### Новые возможности

- `auto-updater`: проверка новых релизов, загрузка пакета под текущую платформу, самозамена и перезапуск — запускается пользователем из UI настроек

### Изменяемые возможности

_Отсутствуют._ Это полностью новая функция, существующие спецификации не затрагиваются.

## На что влияет

- **Новый Go-пакет**: `internal/updater/` (проверка, загрузка, распаковка, установка)
- **Изменяемый Go**: `internal/app/app.go` — новые публичные методы `CheckForUpdates`, `DownloadUpdate`, `InstallAndRestart`, `PendingUpdate`, пробрасываемые во фронтенд через Wails-биндинги; фоновая проверка `checkForUpdatesPassive()` в `Startup`
- **Изменяемый фронтенд**: `SettingsView.vue` — секция «Обновления» + тумблер автопроверки; логика в композабле `composables/useUpdater.ts`; новый компонент `components/layout/UpdateBanner.vue` (баннер), подключённый в `AppShell.vue`; новые ключи i18n для EN/RU
- **Зависимости (Go)**: без новых — всё на стандартной библиотеке (`net/http`, `archive/zip`, `archive/tar`, `compress/gzip`, `os`, `os/exec`, `runtime`, `path/filepath`) плюс `golang.org/x/mod/semver` (уже в проекте)
- **CI/CD**: без изменений — пайплайн релизов уже выдаёт нужные артефакты
