# Скриншоты

Положите сюда три скриншота приложения, на которые ссылается [README.md](../../README.md):

| Файл | Что снять | Рекомендации |
|---|---|---|
| `papers.png` | Раздел **Статьи**: список с видимым скором 0–10, статусами принято/новая/отклонено | полноэкранный или окно ≥ 1400×900, тёмная тема ОС |
| `axes.png` | Раздел **Оси**: карточки осей с must/boost-ключами и диапазоном лет | то же |
| `stats.png` | Раздел **Статистика**: графики распределения по статусам, скорам, годам | то же |

На macOS скриншот окна удобно делать `Cmd + Shift + 4`, затем `Пробел` и клик по окну —
получится PNG с прозрачными полями и тенью.
